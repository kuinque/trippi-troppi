## 1. Обзор продукта

TrippiTroppi — это мобильное приложение с ИИ-агентом, которое формирует персонализированные туристические маршруты по городам России. Приложение помогает туристам быстро и удобно планировать поездки с учетом личных пожеланий, времени и логистики.

---

## 2. Цели и задачи проекта

- **Упростить планирование путешествий**: Автоматизировать подбор и составление маршрутов
- **Персонализировать опыт**: Учитывать интересы, предпочтения, ограничения по времени
- **Увеличить вовлеченность**: Через геймификацию (ачивки), обмен маршрутами, рекомендации
- **Рост пользовательской базы**: Достичь X установок и Y активных пользователей в первый год

---

## 3. Целевая аудитория

- Туристы по России всех возрастов и уровней цифровых компетенций
- Местные жители, желающие открыть новые места или актуальные события в своем городе
- Семьи, индивидуальные путешественники, группы друзей

---

## 4. Ключевые функции (MVP)

### Основные функции

1. **ИИ-агент**: Персональный подбор и построение маршрута
2. **Фильтры интересов**: Пользователь выбирает категории (музеи, парки, еда, выставки и др.)
3. **Динамическое редактирование маршрута**: Возможность вручную корректировать план
4. **Учет ограничений**: Время работы локаций, билеты, транспортная доступность
5. **Автоматическая замена точек**: Если выпала локация или закончились билеты, система предложит альтернативу
6. **Карты и навигация**: Использование Yandex Maps API и OpenTripMap API
7. **Обмен маршрутами, рекомендации, социальные функции**: Делитесь планами, смотрите чужие
8. **Геймификация**: Ачивки, баллы за активность

### Nice-to-have

- Оффлайн-режим для маршрута
- Интеграция с сервисами бронирования билетов
- Push-уведомления о событиях/изменениях

---

## 5. Внешние зависимости и ограничения

- Использование API: Yandex Maps, OpenTripMap
- Корректная работа ИИ–модуля под разные сценарии и категории пользователей
- Правовые ограничения на хранение персональных данных

---

## 6. Пользовательский сценарий (User Flow)

1. Регистрация/авторизация
2. Ввод города и дат / пожеланий
3. Выбор интересов
4. Получение оптимального маршрута
5. Возможность отредактировать маршрут вручную
6. Получение советов, рекомендаций, замена точек при необходимости
7. Навигация и выполнение маршрута
8. Обратная связь / выставление оценки

---

## 7. UX/UI требования

- Интуитивно понятная навигация
- Современный и легкий дизайн, акцент на визуализации маршрута
- Простая настройка фильтров интересов
- Дружелюбный flow редактирования маршрутов
- Возможность делиться маршрутами в один клик

---

## 8. Технологии

- **Клиент**: Flutter
- **Бэкенд**: FastAPI
- **База данных**: PostgreSQL
- **Карты и поиск локаций**: Yandex Maps API, OpenTripMap API

## 9. Архитектура системы

### Backend (FastAPI)

```
backend/
├── app/
│   ├── api/v1/routes/    # API endpoints
│   ├── core/             # Конфигурация, безопасность
│   ├── db/               # База данных
│   ├── models/           # ORM модели
│   ├── schemas/          # Pydantic схемы
│   └── services/         # Бизнес-логика (AI, карты)
```

### Frontend (Flutter)

```
frontend/
├── lib/
│   ├── core/            # Константы, утилиты
│   ├── data/            # Модели, репозитории, API
│   ├── domain/          # Use cases, entities
│   └── presentation/    # UI, state management
```

## 10. Метрики успеха

### Ключевые метрики (KPI)

- **Количество установок**: X в первый год
- **MAU (Monthly Active Users)**: Y пользователей
- **Retention Rate**: Z% через 30 дней
- **Среднее количество маршрутов на пользователя**: N маршрутов/месяц
- **NPS (Net Promoter Score)**: Целевое значение > 50

### Продуктовые метрики

- Время создания маршрута (цель: < 2 минут)
- Процент завершенных маршрутов
- Количество поделенных маршрутов
- Активность в геймификации

## 11. Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Низкая точность ИИ-агента | Средняя | Высокое | Тестирование на разных сценариях, сбор обратной связи |
| Ограничения API (лимиты, стоимость) | Высокая | Среднее | Кэширование, оптимизация запросов |
| Конкуренция с крупными игроками | Высокая | Среднее | Фокус на персонализацию и ИИ |
| GDPR/персональные данные | Средняя | Высокое | Консультация с юристами, прозрачная политика |
